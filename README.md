Dreams Chicken Shawarma — Landing Page (Spec Project)

A bilingual (English / Amharic) landing page concept built for Dreams Chicken Shawarma — a 2-branch fast-casual shawarma, burrito, and taco spot based in Addis Ababa, known first through viral TikTok content.

🔗 Live demo: [dreams-chickenshawarma.vercel.app(https://dreams-chicken-shawarma.vercel.app)

About this project

This is a speculative / unsolicited sample project, built by Possible Technology as part of our program identifying local Addis Ababa businesses that don't yet have a landing page. It was not commissioned by Dreams Chicken Shawarma, and there is no existing business relationship between Possible Technology and Dreams Chicken Shawarma. Public branding, logo, and photos were used to demonstrate what a digital presence could look like for the business, in line with standard agency "spec work" practice.

Tech stack
HTML5
CSS3 (inline / embedded in index.html)
Vanilla JavaScript (inline / embedded in index.html)
Deployed on Vercel
Features
🌐 Bilingual content structure (English / Amharic, Noto Sans Ethiopic for Ge'ez script) built into the markup — the visible language toggle is currently disabled while that feature is finalized
📱 Mobile-first, responsive design, including a mobile hamburger menu
✨ Scroll-reveal animations across every section, plus animated count-up stats (branches, TikTok followers, likes)
🖼️ Lightbox-style photo gallery ("Closer Look") with click-to-expand images
📍 Multi-branch contact/location section with direct "Open in Maps" links per branch
🛵 Delivery partner section covering in-house delivery, RIDE Food, beU Delivery, and Feresegna
💬 Real customer review highlights pulled from public Google and TikTok reviews
🎨 Icon-based UI throughout (no emoji), matching the brand's orange/charcoal/gold palette

# then just open index.html in a browser,

Content sourcing

All business details (branches, menu items, prices, delivery partners) and customer review quotes were gathered from Dreams Chicken Shawarma's public Instagram and TikTok (@dreams_chicken_shawarma), Telegram channel, RIDE Food vendor listing, and Google reviews. No private data, testimonials, or claims were fabricated.
